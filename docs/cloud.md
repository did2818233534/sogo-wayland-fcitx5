# 云候选

适配层请求搜狗 `https://shouji.sogou.com/web_ime/mobile.php`，不依赖 NG 内部未知的云功能开关。这不是账号同步接口。

仅发送当前拼音（小写 ASCII 字母，长度不超过 100），固定设备字段为零值。不发送上下文、已提交内容或真实设备标识。HTTPS 使用 libcurl 默认的证书校验。连接超时 1.2 秒，总超时 2.5 秒；最大响应 64 KiB。接口和结果可能变化。

60 ms 输入防抖；单后台线程以 curl multi 驱动请求，每 25 ms 检查过期状态。复用连接，最多缓存 256 个查询；缓存不写入磁盘。取消输入、切换、上屏和翻页会丢弃旧响应。使用方向键后不会插入迟到候选，防止高亮移动。最多两项云候选置于本页前列并去重，云候选直接上屏；本地候选仍调用引擎的选择接口。翻页展示本地引擎页面。

默认启用云候选。如需离线，在启动 **Fcitx5 本身** 时设置环境变量：

```bash
fcitx5-remote -e
SOGOU_NATIVE_OFFLINE=1 fcitx5 -d
```

该环境变量只要存在就禁用云请求；设成 `0` 也会禁用。永久关闭时在桌面启动 Fcitx5 的环境中设置该变量，重新登录。不要仅把变量放进引擎 systemd 服务，因为网络请求发生在 Fcitx5 插件中。

本次开发环境曾测得首次候选约 377 ms、缓存命中约 68 ms。这是一次集成测试结果，不是延迟保证。
